Network Access Rules and enforcement surface ↗

What it proves

  • The Association publishes an explicit node-governance agreement.
  • Part III describes possible freeze, reassignment, peer, and block directives.

What it does not prove

  • That every directive is fair, enforceable, public, or correctly executed.
  • That courts or key holders cannot err.

Independent inspection path

  1. Read all five parts and current effective dates.
  2. Compare current node and alert behavior with the text.
  3. Request a complete directive history.
